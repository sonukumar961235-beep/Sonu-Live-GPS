# Sonu Live GPS

A consent-based live location sharing app with a White & Green interface.

## Planned features
- Share your own live location only after granting permission
- Invite friends with a code
- View approved friends on a map
- Pause or stop location sharing at any time
- Last-seen status and SOS shortcut

## Project status
Initial project setup. Web and Android app implementation will follow.

## Privacy
This app must never track someone without their knowledge and explicit consent.
